## 🚀 Live Preview & Architecture

A world-class personal portfolio engineered with a dark-mode aesthetic inspired by Apple, Linear, and Vercel. Designed specifically to demonstrate enterprise Zoho CRM development, Deluge scripting, process automation, and full-stack web engineering.

### 🌟 Key Highlights
- **Interactive CRM Sales Pipeline**: Real-time simulated Lead → Contact → Deal → Quote → Invoice state machine with active stage tracking.
- **Deluge Code Preview Modal**: Interactive viewer with copy functionality to showcase real-world Deluge scripts for inventory status logic, GST calculation, and SLA reminders.
- **Project-Based Case Studies**:
  - **Zoho CRM PropTech Suite**: 13 CRM modules, dynamic pricing, Price Books, automated inventory states (Available → Blocked → Sold), 80% manual effort reduction.
  - **MedLine Diagnostics Supply CRM**: B2B medical equipment inquiry handling, custom modules, REST APIs, and automated rep assignment.
  - **Automobile Dealership & Service CRM**: Test-drive booking workflows, vehicle inventory VIN tracking, and periodic maintenance reminders via Blueprints.
  - **API Data Integration & Storage System**: Python REST API ingestion pipeline with batch MySQL storage.
- **Featured Web Portal**: Institutional College Website with interactive browser-window mockup.
- **Resume Hub**: In-browser printable/downloadable professional resume modal.
- **Dynamic Contact Form**: Complete client-side validation, direct email/social links, and celebration feedback.
- **Performance & SEO**: 100% responsive, dark-mode glassmorphism, Google JSON-LD schema, sitemap.xml, robots.txt.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19 & TypeScript
- **Styling**: Tailwind CSS v4 (Glassmorphism & Custom Mesh Gradients)
- **Motion & Animations**: Framer Motion & HTML5 Canvas Particle Engine
- **Icons**: Lucide React & Custom SVG Brand Icons
- **Fonts**: Inter & Fira Code (via `next/font/google`)

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/PremsaiGajula18/MY_PortFolio.git
cd MY_PortFolio

npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the website.

### Production Build

```bash
npm run build
npm run start
```
